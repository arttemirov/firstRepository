## 🛠️ Полезные команды Git

*Отмена последнего коммита с сохранением изменений:*
```bash
git reset --soft HEAD^1
```

*Отмена последнего коммита БЕЗ сохранения изменений:*
```bash
git reset --hard HEAD^1
```

*Безопасное удаление (Git не разрешит удалить ветку, если ее изменения еще не были слияны (merged) в другие ветки):*
```bash
    git branch -d <название_ветки>
```

*Принудительное удаление (если вы точно уверены, что изменения на этой ветке вам больше не нужны и их нужно стереть вопреки предупреждениям Git):*
```bash
    git branch -D <название_ветки>
```
